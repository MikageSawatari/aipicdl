# aipicdl

[Aipictors](https://www.aipictors.com/) のユーザープロフィール URL を指定すると、そのユーザーの公開投稿
(画像・動画・コラム・小説) をまとめてダウンロードし、ブラウザで閲覧できる静的 HTML アーカイブを作る
Windows 用ツールです。exe 1 つで動作し、インストールは不要です。

**自分が投稿した作品を手元にバックアップすること**を目的に作りました。

> 非公式ツールです。Aipictors の運営とは関係ありません。
> ご利用の前に、下の「[サイトへの配慮について](#サイトへの配慮について)」を必ずお読みください。

## 特徴

- **exe 1 つで動く** GUI アプリ (VC++ ランタイムなども不要)
- **サイトに負荷をかけない取得**: リクエストは常に 1 本ずつで、間隔を必ず空けます (詳しくは後述)。
- **途中から再開**: 停止してもう一度実行すると、保存済みの作品は飛ばして続きから取得します。
- **オフラインで閲覧**: 保存先の `index.html` をブラウザで開くと、作品一覧 (種類・レーティング・シリーズでの絞り込み、
  タイトル/タグ/説明の検索、並べ替え) と作品ページを見られます。サーバーは不要です。
- 保存されるもの
  - 画像 (複数枚投稿は全ページ。サーバー上の元ファイルをそのまま保存)
  - 動画 (配信されている最高画質の映像と音声を、再エンコードせず 1 本の MP4 にまとめて保存)
  - コラム・小説の本文 (Markdown のまま `text.md` に保存し、HTML でも表示)
  - タイトル、説明、タグ、レーティング、投稿日時、いいね・閲覧数など
  - 生成情報 (プロンプト、ネガティブプロンプト、モデル、Seed、Steps、PNG info など公開されているもの)
  - コメントと返信 (スタンプ画像・投稿者アイコン含む。オプション)
  - プロフィール (名前、自己紹介、アイコン、ヘッダー画像)、シリーズ (アルバム)
  - API から取得した生データ (`work.json` など。将来ほかのツールで扱えるように)

## サイトへの配慮について

Aipictors は多くのクリエイターが作品を公開している投稿サイトです。このツールは
**サイトの運営やほかの利用者に迷惑をかけないこと**を最優先に設計しています。

### 負荷をかけないための仕組み

- **リクエストは常に 1 本ずつ**送ります。並列ダウンロードは行いません。
- リクエストの間に必ず間隔を空けます。この間隔は**利用者が変更できません**。
  - 作品情報などを取得する API: **3 秒**
  - 画像・動画などのファイル: **1 秒**
- サーバーがエラーを返したときは、10 秒から最大 5 分まで待ち時間を伸ばしながら、最大 5 回まで再試行します。
  サーバーが `Retry-After` (再試行までの待ち時間) を指定した場合はそれに従います。
- 一度保存したファイルは再取得しません。中断後の再実行でも、保存済みの作品は通信せずに飛ばします。
- 取得は、ブラウザで作品ページを 1 件ずつ順に開いていくのと同程度の量になるようにしています。
  作品の情報は 1 作品につき原則 1 回の API リクエストで取得します。
- リクエストの User-Agent には `aipicdl` とこのリポジトリの URL を明記し、運営の方がこのツールからの
  アクセスだと識別・連絡できるようにしています。
- ログインはせず、ログインしていなくても見られる公開情報だけを取得します。

そのため、作品数が多いと時間がかかります (目安: 1,000 作品で 1〜3 時間程度)。ご理解ください。

### ご利用にあたってのお願い

- **同時に複数起動したり、複数のユーザーを並行して取得したりしないでください。**
- 必要なときに実行してください。タスクスケジューラなどで**定期的に自動実行することはお控えください**。
- 間隔を短くする・並列化するなど、**サイトへの負荷を高める改造をして使わないでください**。
- エラーが続くときやサイトが重いときは、いったん停止して時間をおいてから再開してください。
- [Aipictors の利用規約](https://www.aipictors.com/terms)を守ってご利用ください。
- **他の方の作品の著作権は作者にあります。** 保存した作品は個人的な閲覧の範囲にとどめ、
  再配布・再投稿・無断転載などは行わないでください。

## 使い方

1. [Releases](https://github.com/MikageSawatari/aipicdl/releases) から zip をダウンロードし、`aipicdl.exe` を好きな場所に置きます。
2. `aipicdl.exe` を起動します。
3. 「プロフィール URL」に `https://www.aipictors.com/users/○○` を貼り付けます (ユーザー ID だけでも可)。
4. 保存先フォルダを選び、「ダウンロード開始」を押します。
5. 終わったら「index.html を開く」でアーカイブを閲覧できます。

途中で「停止」してもかまいません。次回は続きから再開します。

配布している `aipicdl.exe` にはコード署名とタイムスタンプが付いています。ファイルのプロパティの
「デジタル署名」で、署名者が **Open Source Developer Taku Sano** であることを確認できます。
新しいバージョンの公開直後は、Windows の SmartScreen が警告を出すことがあります。

「詳細設定」では次の項目を変えられます。

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| コメントも保存する | オン | コメント・返信・スタンプ・投稿者アイコン |
| 動画も保存する | オン | 動画作品の動画ファイル |
| 保存済みの作品も情報を取り直す | オフ | いいね数やコメントを最新にしたいとき。画像などは再取得しません |

設定は `%APPDATA%\aipicdl\settings.json` に保存されます。

### コマンドライン

引数を付けて起動すると GUI を出さずに実行します (`start /wait aipicdl.exe ...` のように実行すると出力を待てます)。

```
aipicdl <プロフィールURL> [--out <DIR>] [--no-comments] [--no-videos] [--refresh] [--limit <N>] [--ids <ID,ID,...>]
aipicdl --render-only <保存済みのユーザーフォルダ>   # 通信せず HTML だけ作り直す
```

## 保存されるフォルダ構成

```
<保存先>/<ユーザーID>/
├── index.html            作品一覧 (これをブラウザで開く)
├── assets/               一覧・作品ページ用の CSS / JS
├── data/
│   ├── user.json         プロフィール (API の生データ)
│   ├── works.json        全作品のメタデータをまとめたもの
│   └── work_ids.json     最後に取得した作品 ID 一覧
├── user/                 アイコン・ヘッダー画像
├── works/<作品ID>/
│   ├── index.html        作品ページ
│   ├── work.json         作品のメタデータ (API の生データ + 保存したファイルの情報)
│   ├── 00.webp, 01.webp…  画像 (動画・コラム・小説ではサムネイル / 表紙)
│   ├── thumb.jpg         一覧用の縮小画像
│   ├── video.mp4         動画
│   ├── text.md           コラム・小説の本文
│   └── comments.json     コメント
├── stickers/             コメントのスタンプ画像
├── icons/                コメント投稿者のアイコン
└── aipicdl.log           実行ログ
```

## 制限事項

- ログインはしません。取得できるのはログインしていなくても見られる公開作品だけです
  (下書き・非公開・限定公開などは含まれません)。
- 画像は Aipictors のサーバーに保存されている形式 (主に WebP) のまま保存します。
  サイトの「ダウンロード」ボタンは同じ画像をブラウザ内で PNG に変換しているだけなので、画質は同じです。
- コレクション (他ユーザーの作品のブックマーク集) やフォロー情報は保存しません。
- サイトの仕様が変わると動かなくなる可能性があります。
- アーカイブには R18 などのセンシティブな作品も含まれます。取り扱いにはご注意ください。

## 開発・改造について

ソースコードは MIT License で公開しています。改造や再配布は自由ですが、次の点をお願いします。

- リクエスト間隔の短縮、並列化、アクセス制限の回避など、**サイトへの負荷を高める変更は行わないでください**。
  そのような変更のプルリクエストは受け付けません。
- 改造版を配布する場合は、`src/net.rs` の `USER_AGENT` を変更し、本ツールと区別できるようにしてください
  (運営の方が問題のあるアクセスを正しく識別できるようにするためです)。

### ビルド

Rust (1.88 以降) と Windows SDK が必要です。

```
cargo build --release
```

`target/release/aipicdl.exe` ができます。署名付きの配布物の作り方は [docs/release.md](docs/release.md) を参照してください。
